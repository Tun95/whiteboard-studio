# Whiteboard Wave Studio: progress and next steps

Goal: a FREE Windows app (with a Donate button) that turns scripts + images into whiteboard videos.
Built from `whiteboard-animator` (MIT) + Kokoro voice. Owner: Akande Tunji.

## Design decisions
- The window is a local web page (`studio/static/index.html`) served only to this computer by `studio/server.py`
  (stdlib only). Reason: it can be fully tested in the cloud workspace, no window toolkit needed.
- `studio/engine.py` runs Kokoro (`studio/voice_kokoro.py`) and the animator as separate steps.
- Installer v1 = animator + UI + FFmpeg only (small). Kokoro/PyTorch is an optional add-on: set `kokoro_python`
  in `Documents\WhiteboardWaveStudio\settings.json`, or it auto-finds `Desktop\White Board Animation\_Tools\kokoro\kokoro-env`.
- Donate link: `donate_url` in settings.json (empty = "coming soon"). Need the user's donation page link.

## Phase 4: Text to speech + Transcribe
- [x] Text to speech tab: own text (typed, pasted or .txt) -> WAV + MP3 in the Library/Editor audio list. Reuses `voice_kokoro.py` (styles, speed, [pause N], # notes, pronounce fixes). Resumable for long texts (work folder keyed by a hash of text+settings). Tested with the Kokoro stub only.
- [x] Transcribe tab: faster-whisper (MIT) in its own add-on environment `<data>/stt/env` (created by the "Set up transcription" button; installs faster-whisper, python-docx, reportlab). Models download on first use into `<data>/stt/models` (base ~150 MB, small ~480 MB, medium ~1.5 GB). Audio is extracted with FFmpeg to 16 kHz mono first, so any video works. Editable transcript with click-to-play times; export TXT / SRT / VTT (pure Python) and DOCX / PDF (worker `stt_worker.py` in the add-on env); "Add as captions in the Editor".
  - NOT verified with a real model: the sandbox could not reach huggingface.co. The worker was written against faster-whisper 1.2.1 (signatures checked) and tested with a stub (`tests/stubs/faster_whisper`). First real run is on the user's PC.
  - Whisper does not support Igbo or Zulu (checked in faster-whisper's language list). Yoruba and Hausa are supported but less accurate.
  - PDF: Latin/Cyrillic/Greek via a system font (Segoe UI/Arial/DejaVu), Chinese/Japanese/Korean via built-in PDF fonts, other scripts (Hindi, Arabic, Thai) give a friendly "use Word" message. DOCX/TXT/SRT/VTT keep every character.
  - CPU only (int8). GPU not used.
